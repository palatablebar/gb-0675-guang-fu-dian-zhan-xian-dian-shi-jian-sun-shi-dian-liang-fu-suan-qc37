# 功率与限电定义

设备额定功率为kW。遥测kW与MW统一为kW，辐照度为W/m²。样本时刻须带偏移，统一UTC。记录代表自采样时刻起600秒的左值保持区间，超过600秒不外推，缺测保持未定。
每台设备重叠或相邻限电事件先求并集，再按遥测及有效期边界切分半开区间。样例INV-A的10:00–10:20及10:10–10:30合并为30分钟，不能重复积分重叠10分钟。
基线只采用同区域、同采样时刻、同100W/m²辐照档、健康且不处于限电中的参考逆变器；至少2台。对参考功率按各自额定功率归一，取中位数再乘目标额定功率，基线不超过目标额定功率。无合格对照返回NO_REFERENCE及null损失，不填0。
每片段损失=max(基线−实际,0)×秒数/3600。实际高于基线时损失0。计算保留Decimal精度，汇总后统一保留0.0001kWh；未定时长单独展示，不并入已确定损失。
清批INV-A基线100kW、实际60kW、并集30分钟，损失20kWh；INV-B基线50、实际30、20分钟，损失6.6667kWh。总确定损失26.6667kWh。能量核验按实际+非负损失计算可解释基准电量。
同设备同一时刻不同观测全部隔离；同值重复观测保留稳定编号。封存需无隔离和未定片段。此工具供离线复算，不包含生产控制或电网调度。

# 场站限额与设备级分摊
LIMIT记录为场站级限额：device留空，power+unit为限额，start/end为窗口；指定设备的限额记录隔离（LIMIT_DEVICE）。区间重叠且限额不一致的记录双双隔离（LIMIT_CONFLICT）；同值重叠或相邻先求并集。OUTAGE记录为设备级停运（组串停运等）：power+unit为停运容量，不得超过设备额定；同一设备重叠停运取最大声明容量。
限额窗口按全场遥测边界与停运边界切片。每片每设备：基线由对照逆变器拟合（故障设备同样估计应发）；停运=故障全额或组串停运声明，故障优先不叠加；可发=基线−停运。场站限电=max(0,Σ可发−限额)，按各设备可发占比分摊到设备，形成可归责的设备级限电损失。停运电量与限电电量是同一基线的互斥两部分，同一不可发电量不会既算停运又算限电。分摊合计与限额口径在0.0001kWh精度对平。
设备级限电事件覆盖的片段不参与分摊，整片待查（LIMIT_EVENT_OVERLAP）；对照不足或缺测的片段同样待查，限电保持null不填0。待查片段不计入分摊合计，封存须无待查片段。
午间限额批INV-A限电2.5641kWh、INV-B限电0.7692kWh，分摊合计与限额口径3.3333kWh对平；INV-B停运15kWh（故障一片全额8.3333、组串停运两片各3.3333）；12:30东区对照不足留1个待查片段。
